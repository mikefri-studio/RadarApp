🔒 Politique de confidentialité

  • Aucune donnée personnelle collectée ni transmise à des tiers
  • Aucun tracking de vos déplacements ou trajets
  • Aucun compte utilisateur requis
  • Vos radars personnalisés et préférences restent sur votre téléphone
  • La position GPS sert uniquement à afficher les radars proches

⚖️ Utilisation légale

  • Avertisseur de radars fixes autorisé (article R413-15 du Code de la Route)
  • Données publiques librement réutilisables
  • L'application ne détecte pas les radars mobiles en temps réel
  • Engagement : les contrôles mobiles ne seront jamais partagés entre utilisateurs, même dans une future fonctionnalité communautaire (conformité LOPPSI 2)

💻 Technologies

  • Cartographie : MapLibre GL JS + tuiles Protomaps
  • Framework : Android WebView
  • Données : data.gouv.fr (gouvernement français)
  • Mises à jour : GitHub Actions
